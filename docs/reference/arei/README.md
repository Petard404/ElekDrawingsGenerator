# AREI symbol library

Symbols by ShadowHunter (www.arei-rgie.be), added on 11 October 2026. Licence in `LICENSE.txt`: free to use, modify and integrate into diagrams; the licence text must stay with the files when they are redistributed.

| Folder | Content |
| --- | --- |
| `svg-en/` | 102 SVG symbols, English names, from before the 2023 amendment. Each comes as a single-line version and a "for floorplan" version. The two unofficial PV symbols are left out |
| `visio-2023-nl/` | 9 Visio stencils (`.vssx`) with the 2023 update, Dutch names. A `.vssx` is a zip of XML; the shapes are in `visio/masters/`. Visio is not available, so needed shapes are converted to SVG by script (see `docs/plan-review.md`) |

Only the 2023 stencils contain: Differentieel 2023, Laadinrichting voor elektrische wegvoertuigen, Aardingsonderbreker, Aardingsstrip, Aardinrichting, Schakel- en verdeelbord, Domotica sturingseenheid, Bewegingssensor, and the "voor ééndraadsschema" variants of the appliances.

Not in the library: surge protection, and a dedicated CV boiler symbol (Verwarmingstoestel is used).
