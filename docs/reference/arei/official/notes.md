# AREI Book 1, table 2.23 "Grafische symbolen": notes

Source: AREI Bijlage Boek 1, 2026 edition, chapter 2.13, table 2.23 (printed pages 55–62, PDF pages 60–67). Extract: `arei-boek1-tabel-2.23-grafische-symbolen.pdf`. The table is non-exhaustive ("niet-limitatieve lijst") and covers the single-line diagram and the position plan of a household installation. Read once on 11 October 2026; work from these notes.

## Sections in the table

| Section | Contents relevant to us |
| --- | --- |
| A. Algemeenheden | DC, AC, single-phase "1~", three-phase "3~" |
| B. Elektrische toestellen | Schakel- en verdeelbord (rectangle; example with outgoing lines on top), doos, aftakdoos, aftakkast, aardingsonderbreker |
| C. Elektrische leidingen | Leiding; underground, overhead, in conduit, in wall, on wall; "n elektrische leidingen"; conductors: three slashes for 3, one slash with "n" for n conductors (n = total number of conductors) |
| D. Beschermingstoestellen | Fuse (with "gG 16A"), automatische schakelaar (letters M, O, Δ for trip mechanisms), differential, small breaker, aardelektrode |
| E. Schakelaars | Switches, push button, time switch, impulsschakelaar (rectangle with two contact marks), thermostat, bewegingssensor, switch in a board |
| F. Contactdozen | Socket; multiple socket (stacked, or one socket with "3" and a slash); waterproof "h"; with protective conductor; with child protection; both; with switch; with transformer; data socket |
| G. Gebruikstoestellen | Light point (cross), wall light, fluorescent, projectors, emergency lighting, bell, buzzer, horn, siren, clock, door lock, fan, verwarmingstoestel (box with vertical bars), with accumulation, boiler (circle with vertical bars), boiler with accumulation, vast huishoudtoestel (empty square), fornuis/kookplaat (square, three dots), microgolf, oven, wasmachine, droogkast, afwasmachine, koelkast, diepvriezer, motor (circle "M"), laadinrichting voor elektrische wegvoertuigen, kWh-teller |
| H. Bronnen | Transformer (with Uprim/Usec, Pn), PV panel, converters (with Pmax, U prim, U sec) |
| J. Domotica | Control unit: rectangle in two parts, bottom = base symbol (switch, socket), top = control type (push button, wireless, programmed, push-button extension, detection) |

## Label formats the table prescribes

These matter more than the shapes, because they change the text we draw:

| Item | Official example | House A original |
| --- | --- | --- |
| Small breaker | Switch symbol with "C20" (curve + rating) | "20A" |
| Differential | Switch symbol with "40/0.3A" and "type A" (In / ΔIn in A, then type) | "300 mA 4x40 A" with a triangle |
| Cable | "XVB Cca 5G4²", "XVB Cca 3G2.5²", "H07V-U Eca 1.5²": cable type, CPR fire class, cores G section, decimal point | "XVB 3x2.5" |
| Fuse | "gG 16A" | none |

## Not in the table

Surge protection, a CV boiler symbol (Verwarmingstoestel is used), and House A's square-with-triangle.
